# Nalendar

Nalendar is a modern terminal calendar application for managing events in one place.

It is being designed to support native events inside the app while also syncing and manipulating calendars from external providers.

## Development Status

Nalendar is in early development. The project is currently focused on the core terminal experience and the foundations for calendar and event synchronization.

## Goals

- Create and manage local events
- Sync calendars from external providers such as Google and Outlook
- View and manipulate events from a single terminal-first interface
